【グリッドシステムの実装】

  1. メニューページ（menu.html）
     • コースメニュー
       - グリッド設定：grid-template-columns: repeat(auto-fit, minmax(300px, 1fr))
       - gap: 2rem でカード間に均等な空間
       - 3列レイアウト（デスクトップ）
       - レスポンシブ対応：タブレットで2列、スマホで1列に自動調整
       
     • グラスワイン
       - grid-template-columns: repeat(4, 1fr)
       - 4列レイアウト（デスクトップ）
       
     • チーズメニュー
       - grid-template-columns: repeat(3, 1fr)
       - 3列レイアウト
       
  2. ホームページ（index.html）
     • intro-grid
       - repeat(auto-fit, minmax(280px, 1fr))
       - 自動レスポンシブ調整
       
     • features-grid
       - repeat(auto-fit, minmax(250px, 1fr))
       - ホバー時：translateY(-8px) + box-shadow で立体的動作
       
  3. フッター
     • footer-content
       - grid-template-columns: repeat(auto-fit, minmax(250px, 1fr))
       - 3つのセクション（店舗情報、ナビゲーション、営業時間）を自動配置

【画像処理の工夫】

  1. トリミング・アスペクト比の統一
     • メニューカード画像
       - height: 250px で統一（.menu-image）
       - object-fit: cover で画像を完全に埋める
       - overflow: hidden で縁をカット
       
     • ワイン・チーズ画像
       - 同様の高さ統一（250px）
       - 正方形に近い形で表示
       
  2. CSS での視覚的調整
     • border-radius: 4px で角を丸める
     • 画像コンテナ：background-color: #f0f0f0（グレー背景）
     • box-shadow で立体感を付与
     
  3. ホバーエフェクト
     • .menu-card:hover
       - transform: scale(1.05) で拡大（5%）
       - box-shadow: 0 4px 12px rgba(...) で影を強調
       - transition: 0.3s ease で滑らか
       
     • 画像の透視度（opacity）：ホバー時に微調整
     
  4. 背景色との調和
     • ページ背景：#f8f8f8（明るいグレー）
     • カード背景：#fff（白）
     • 画像コンテナ：濃いグレーで フレーミング効果
     
  5. 色調変換
     • CSS filter は使用しない（画像自体を調整済みと想定）
     • 照明効果：box-shadow のグラデーション色で奥行きを表現
